# Tinghao Moe Knowledge Base

挺好萌文本知识库，项目标识为`tinghao-moe-knowledge-base`。

本项目围绕挺好萌整理公开赛事资料，供查阅、检索增强生成（RAG）和个人知识库使用。内容涵盖赛事沿革、规则、历届赛果、角色战绩、提名与禁赛名单，以及社区文献和站点工具。项目由第三方整理，与赛事主办方及来源站点无隶属关系。

事实正文以中文为主，保留来源中的作品名、角色名、别名和比赛标识。

## 资料范围

资料来自[挺好萌网站](https://tinghao.moe/)的公开页面与赛事数据。当前版本采集于2026年10月31日，整理范围涉及2017—2026年归档中的202场比赛、5810条参赛记录、3729名角色和976个作品条目。提名名单覆盖2024—2026年，禁赛名单保留采集时状态。

上传版本共有36篇Markdown分卷，约350万字符。赛果与角色战绩保留票数、排名、得票率、结果和异常备注；介绍与规则采用转述，30篇社区文献保留署名、日期、概述和原帖入口。长篇应援、评论和同人叙述的概述不保证保留原文每一项细节。图片、音视频和外部百科正文不在文本范围内。

覆盖记录用于说明指定范围内的读取和整理结果，不能据此推定全部相关内容均无遗漏，也不能代替对原始投票或社区观点的核查。实时计票、无法加载的1v1结果及其他例外，见[完整性口径与例外](说明与索引/完整性口径与例外.md)。

## 分层目录

[核心必读](上传用Markdown/01_核心必读_赛事概览与规则)集中赛事介绍、规则及历史版本说明、历届挺王与夺冠路径，适合建立通用挺好萌知识库。

[直接相关](上传用Markdown/02_直接相关_赛程名单与禁赛)收录赛程、提名、禁赛名单与分组图入口。[赛果与战绩专项](上传用Markdown/03_专项资料_赛果与角色战绩)进一步保留完整归档赛果、淘汰赛结构和角色历史战绩，支持逐场与角色两种检索视角。

[文献与社区文化](上传用Markdown/04_延伸阅读_文献与社区文化)集中30篇文献概述及原帖入口，涵盖概念讨论、角色分析和应援创作，适合补充赛事的社区语境。

[外围参考](上传用Markdown/05_外围参考_作品索引与站点工具)保存作品名称映射、检索标签、工具说明和贡献者署名。层级表示通用问答的建议检索优先级，具体导入范围可按用途调整。

## 使用方式

从[上传用Markdown](上传用Markdown)选择所需层级内的.md文件，导入支持Markdown的知识库。完整文件目录见[资料目录](说明与索引/资料目录.md)。本文本库尚未生成向量索引，也不包含训练完成的模型。

[覆盖记录](覆盖记录)保留来源地址、文件哈希、分层映射和核验结果，供程序处理与追溯。原始采集缓存与临时工具已清除；采集核验记录反映清理前的检查，当前36篇正文另附文件哈希清单，便于核对。

使用时应区分主赛与特别赛、提名与实际出战、历史战绩与当前禁赛状态，并保留规则版本和发文日期。社区观点、角色关系解读、同人叙述和赛前预测不应直接当作官方设定或最终赛果。作品级标签也不等同于角色个人属性。

## 来源与许可

资料按采集时公开网站的内容整理，后续变化请以原页面为准。原站文字、社区文章及素材的权利归相应权利人，使用时应保留署名与来源。

本项目未在核对范围内确认原站统一的开放内容许可。项目采用事实整理、规则转述和文献概述，不对第三方文字或素材另行授予许可，也未将整库统一声明为MIT等软件许可。公开仓库的可访问性不构成第三方内容的新授权，复用时应按具体来源确认适用条件。详细说明见[来源与使用说明](说明与索引/来源与使用说明.md)。

## 纠错与贡献

欢迎修正比赛数据、角色关联、分类和版本说明。提交修改时，请说明涉及的文件与比赛编号或条目，并附可核对的来源；来源相互冲突时保留差异和时间语境。涉及第三方文字的补充应同时说明许可或使用依据。
