# 站内工具与实时状态

本站使用带井号的页面路由。[参赛名单](https://tinghao.moe/#/roster?tab=list)、[角色战绩](https://tinghao.moe/#/record)和[历史记录](https://tinghao.moe/#/result)提供不同检索入口。名单支持搜索和生成投票内容，战绩页可以按角色和条件筛选；浏览器中的分页只是显示方式，知识库从完整数据接口整理全部记录。

采集日期为2026年10月31日。[实时计票接口](https://tinghao.moe/api/realtime/vote.json)返回no_match，即暂无比赛。时序图接口返回404，不能据此补造比赛曲线，也不能把休赛占位理解为所有历史记录都没有投票。实时页面还可以通过比赛参数回看已归档场次，知识库将这些内容归入历史赛果。

[应援图生成器](https://tinghao.moe/support-card/)支持单张和批量生成，可选角色、裁剪头像、填写角色名、罗马字、应援词和署名，并提供JPG、PNG及AVIF下载入口。本次只读取工具说明与公开角色索引，没有替用户生成或上传图片。

[猜角色](https://tinghao.moe/guess/)通过猜测角色并比较禁赛类型、得票率、比赛与届数、最佳成绩和作品标签等线索进行游戏。配置支持按最近届次、最佳排名、总参与次数等条件限制范围，页面提供四强、八强、十六强等预设。作品标签属于检索提示，不能全部解释为角色个人属性。

[1v1](https://tinghao.moe/vs/)说明其角色名单来自一类、二类禁赛名单，用户可以选择支持的角色并查看投票结果。采集时页面提示无法加载新投票对，未取得完整对战结果。本库保留这一例外，没有执行投票。

站内[比赛视频入口](https://tinghao.moe/video/)提供视频制作界面。采集时页面提供上传数据、背景音乐和调色文件的入口，可以设置分辨率、帧率、更新间隔、开始位置、音视频码率、背景颜色、头像尺寸与分组，并提供预览、录制和离线导出WebM。它是条形图视频制作工具，不能把工具页面当作完整视频库。视频画面、音频、图片内文字和外部页面没有纳入正文转录。

角色卡中的Bangumi、萌娘百科等外部资料依赖第三方接口。这里保留站点提供的角色编号、题名和入口，不将外部百科的当前正文视为已采集内容。获取外部资料失败也不代表角色不存在。
